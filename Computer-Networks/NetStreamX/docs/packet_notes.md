# Packet Notes

## What is a Packet?

A packet is the basic unit of communication in computer networks.

A packet contains:

- Source Address
- Destination Address
- Protocol Information
- Payload

---

+--------------------+
| Payload            |
+--------------------+

---

## Examples

Protocol:
- TCP
- UDP
- ICMP

Payload:
- Message
- File Data
- HTTP Request
