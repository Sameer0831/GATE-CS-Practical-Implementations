# TCP vs UDP

| Feature | TCP | UDP |
|----------|----------|----------|
| Connection | Connection-Oriented | Connectionless |
| Reliability | Reliable | Unreliable |
| Ordering | Ordered | Unordered |
| Speed | Slower | Faster |
| Handshake | Yes | No |
| Error Recovery | Yes | No |
| Congestion Control | Yes | No |

---

## TCP Applications

- HTTP
- HTTPS
- FTP
- Email

---

## UDP Applications

- DNS
- Gaming
- Video Streaming
- VoIP
