# HTTP Notes

## HyperText Transfer Protocol

HTTP is an application layer protocol used for communication between clients and web servers.

---

## Request Response Model

Client
→ HTTP Request

Server
→ HTTP Response

---

## Common Methods

### GET

Retrieve data.

### POST

Send data.

### PUT

Update data.

### DELETE

Delete data.

---

## HTTP Response Codes

200 OK

404 Not Found

500 Internal Server Error

301 Redirect

---

- Websites
- REST APIs
