# TCP Notes

## Transmission Control Protocol (TCP)

TCP is a connection-oriented transport layer protocol.

Before communication starts, TCP establishes a connection using a three-way handshake.

---

## Characteristics

- Connection-Oriented
- Reliable
- Ordered Delivery
- Error Detection
- Flow Control
- Congestion Control

---

## Three-Way Handshake

1. SYN
2. SYN-ACK
3. ACK

Connection Established

---

## Common Applications

- Web Browsing (HTTP/HTTPS)
- Email
- File Transfer
- Database Connections
